# Map Providers

> Choose your imagery source for geospatial AI analysis

## Supported Providers

| Provider                           | Features                                  | Authentication |
| ---------------------------------- | ----------------------------------------- | -------------- |
| [Geobase](./map-providers/geobase) | Your COG imagery, multispectral support   | API Key        |
| [Mapbox](./map-providers/mapbox)   | Global satellite imagery                  | Access Token   |
| [ESRI](./map-providers/esri)       | Global satellite imagery, ArcGIS services | None (Public)  |
| [TMS](./map-providers/tms)         | Custom raster tile URLs (COG, XYZ pyramids) | Optional       |
| [WMS](./map-providers/wms)         | OGC WMS GetMap (e.g. Geobasis NRW orthophotos) | None (public)  |
| Google Maps                        | 🚧 Coming Soon - Global satellite imagery | -              |

<Callout type="info" emoji="💡">
  **Geobase** — your own COG imagery with full control. **Mapbox / ESRI** — ready-to-use
  global satellite coverage. **TMS** — any raster `{z}/{x}/{y}` URL. **WMS** — OGC GetMap
  endpoints. See [Serving raster tiles](./map-providers/serving-raster-tiles) for COG and
  tile-server options.
</Callout>
